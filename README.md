# ProjectHub API 

## Sobre o Projeto
O **ProjectHub** é um sistema Back-end (API) desenvolvido para organizar e gerenciar projetos e suas respectivas tarefas. Ele serve como o "motor" de um gerenciador de tarefas, permitindo que o usuário crie escopos de projetos e adicione atividades pendentes a eles. 

## Funcionalidades
**Gerenciamento de Projetos:** Criação, listagem, atualização de nomes e exclusão de projetos.
**Controle de Tarefas:** Adição de tarefas vinculadas a um projeto específico, alteração de status (Ex: Pendente, Em Andamento, Concluído) e exclusão.
**Organização Relacional:** Se um projeto é apagado ou consultado, o sistema entende a relação entre ele e as tarefas que lhe pertencem.

## Tecnologias Utilizadas
**Python 3**
**FastAPI:** Framework moderno e ultrarrápido para criação da API.
**PostgreSQL:** Banco de dados relacional robusto para armazenar as informações.
**Psycopg2:** Biblioteca para conectar o Python ao PostgreSQL de forma nativa.
**Swagger UI:** Documentação interativa gerada automaticamente.
